# Screen Off · YouTube + YouTube Music (Android)

Standalone Android app in the Laifu monorepo, under \`apps/youtube-screenoff/\`. No game files need to change.

## Tabs (v0.2)
- **YouTube:** browse \`m.youtube.com\`, search videos, or paste YouTube watch / Shorts links.
- **Music:** browse \`music.youtube.com\`, search songs, or paste YouTube Music links.
- Each tab keeps its own WebView/history and address bar draft.
- Tap the red **PUTAR AUDIO/MUSIK · LAYAR MATI** button after opening one song/video. A Media3 background playback service plays the audio; the audio keeps playing when you use the phone's lock button.
- Play/pause is accessible from Android's media notification and lock screen.
- Sharing a \`music.youtube.com/watch?v=...\` URL to the app automatically opens the Music tab.
- Music watch URLs are converted to standard \`www.youtube.com/watch?v=...\` for the NewPipe audio resolver.

## Get the APK
Go to **Actions → YouTube Screen Off APK** and download the \`youtube-screenoff-debug-apk\` artifact of the latest successful run. Extract ZIP and install \`app-debug.apk\`.

Android 8+; no root required. App ID: \`art.lafrich.screenoff\`.

Build locally using Java 17, Android SDK 35, and Gradle 8.10.2:
\`\`\`sh
cd apps/youtube-screenoff
gradle :app:assembleDebug
\`\`\`
Output: \`app/build/outputs/apk/debug/app-debug.apk\`.

### Updating an earlier test APK
The APK generated by GitHub Actions uses Android's **debug signing key**. Since each CI runner may create a different signing key, Android might refuse an in-place upgrade with a signature mismatch. In that case **uninstall the previous test APK first**, then install the new one. This resets cookies/local app data. Production upgrades should use a stable, privately stored release signing key.

## Limitations
- This is **not the official YouTube or YouTube Music app**, and does not bypass Google account or paid subscription restrictions.
- WebView browsing, especially YouTube Music account login, may be unsupported or blocked on some phones. Playback of protected, private, membership-only, paid, age-restricted and DRM material is not supported.
- A single selected video/song can play in the background. **Automatic playlist progression, downloads, playlists, and music library sync are not implemented.**
- The NewPipeExtractor project is unofficial and may break when YouTube changes its interfaces. Audio playback might fail for some songs despite successful installation.
- Music switching works via a separate audio stream; the built-in web player does not itself run in the background.
- Device-level testing is necessary even after GitHub Actions successfully compiles the APK.
- Some phones need battery optimization disabled for reliable background playback.
